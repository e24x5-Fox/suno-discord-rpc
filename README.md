# 🎵 Suno → Discord Rich Presence

Показывает текущий трек из Suno AI в активности Discord:
- **Название трека** и **исполнитель**
- **Прогресс-бар** (заполняющаяся полоса)
- **Обложка трека**

---

## Как это работает

```
suno.com  →  Расширение Chrome  →  Python сервер  →  Discord
(плеер)      (читает данные)       (WebSocket)        (Rich Presence)
```

---

## Установка — 3 шага

### Шаг 1 — Создай Discord приложение (1 раз)

1. Иди на [discord.com/developers/applications](https://discord.com/developers/applications)
2. Нажми **New Application**
3. Дай любое имя, например `Suno Player`
4. Скопируй **Application ID** — он понадобится дальше

> 💡 Опционально: во вкладке **Rich Presence → Art Assets** можно загрузить
> логотип — он будет показываться как маленькая иконка рядом с обложкой.

---

### Шаг 2 — Настрой и запусти Python скрипт

**Установи зависимости:**
```bash
pip install -r python/requirements.txt
```

**Вставь свой Client ID в файл `suno_rpc.py`:**
```python
DISCORD_CLIENT_ID = "123456789012345678"  # ← сюда
```

**Запусти:**
```bash
python suno_rpc.py
```

Ты должен увидеть:
```
==================================================
  🎵 Suno → Discord Rich Presence
==================================================
✅ Discord подключён!
🌐 Запускаю WebSocket-сервер на порту 6969...
```

---

### Шаг 3 — Установи расширение в Chrome

1. Открой Chrome → адресная строка → `chrome://extensions`
2. Включи **"Режим разработчика"** (переключатель справа вверху)
3. Нажми **"Загрузить распакованное расширение"**
4. Выбери папку `extension` из этого архива
5. Расширение появится в панели браузера

> ⚠️ **Важно:** расширение работает только пока Python скрипт запущен.
> Запускай `suno_rpc.py` **перед** тем как открываешь Suno.

---

## Использование

1. Запусти `python suno_rpc.py`
2. Открой [suno.com](https://suno.com) в Chrome
3. Начни воспроизведение любого трека
4. Через несколько секунд в Discord появится статус

**Нажми на иконку расширения** чтобы проверить:
- 🟢 `Подключён` — Python сервер работает
- `▶ Играет` — трек найден и транслируется

---

## Частые проблемы

| Проблема | Решение |
|---|---|
| `Не удалось подключиться к Discord` | Убедись что Discord запущен. Проверь Client ID |
| Статус не появляется | Включи **Настройки → Конфиденциальность → Отображать активность** в Discord |
| Расширение не видит трек | Обнови страницу suno.com после установки расширения |
| Прогресс-бар не отображается | Это нормально на паузе — Discord показывает полосу только при воспроизведении |
| Обложка не отображается | Discord иногда кеширует изображения. Подожди 1-2 минуты |

## Структура файлов

```
suno-discord-rpc/
├── extension/            ← папка расширения Chrome
│   ├── manifest.json
│   ├── content.js        ← читает данные плеера со страницы
│   ├── background.js     ← WebSocket клиент + аудиозахват
│   ├── offscreen.js/html ← FFT-анализ звука для визуализации
│   ├── popup.html        ← интерфейс расширения
│   ├── popup.js
│   └── icons/
└── python/
    ├── suno_rpc.py       ← главный скрипт (WebSocket сервер + Discord RPC + трей)
    ├── suno_stats.py     ← статистика прослушиваний, HTML-отчёт
    ├── requirements.txt
    ├── build.bat         ← сборка .exe (PyInstaller)
    ├── suno_rpc.spec         ← релизная сборка (без консоли)
    └── suno_rpc_debug.spec   ← debug-сборка (с консолью)
```

---

## Сборка .exe (Windows)

```bash
cd python
build.bat
```

Соберёт `dist\SunoRPC.exe` (без консоли — для обычного использования) и
`dist\SunoRPC_debug.exe` (с консолью — чтобы видеть ошибки при отладке).
Требуется Python и `pip install pyinstaller` (ставится автоматически скриптом).

---

## Технические детали

- Расширение читает `<audio>` элемент страницы каждые 2 секунды
- Данные передаются через WebSocket на `localhost:6969`
- Discord обновляется не чаще 1 раза в 15 секунд (ограничение API)
- Прогресс-бар реализован через `start_timestamp` + `end_timestamp`
- Обложка передаётся как прямая ссылка на CDN Suno
